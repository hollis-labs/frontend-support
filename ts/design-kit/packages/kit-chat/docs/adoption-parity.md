## Shared gaps after this slice

- [I] A chatstream binding with measured typing latency, batching and history/queue/session behavior is a separate frontend lane task. This checklist does not claim those features are complete.
- [I] Tool result rendering and the full lossless envelope belong to the separate tool-card slice. The per-kind renderer is only a presentation hook.
- [I] Each app still needs an adapter from its own session/events to `ChatItem[]`, plus its own actions, transport and approval reconciliation. The owner will direct adoption later.
- [V] The default kit textarea cannot display an inline rich mention chip; `renderEditor` is the seam for a host rich editor. The demo shows a minimal second editor, not Nanite's Tiptap behavior.
